# kali-zsh-setup

Автономный самодостаточный скрипт для развёртывания окружения Kali Linux Zsh на любой машине под управлением Debian или производных дистрибутивов (Ubuntu, Devuan и др.).

Шаблоны `.zshrc` и `.zprofile` из апстрима Kali Linux (`kali-defaults`) встроены внутрь файла через heredoc с контролем целостности sha256. Внешние SSH-соединения, хост Kali или сетевые загрузки шаблонов не требуются.

## Возможности

- **Полная автономность**: один файл `kali-zsh-setup.sh`.
- **Системный охват**: настройка `/etc/skel` и всех интерактивных учетных записей (UID 0 и UID ≥ 1000 с валидным шеллом).
- **Безопасная модель привилегий**: при запуске от непривилегированного пользователя автоматически вызывает `sudo`; защищён от запуска из пайпа (`curl ... | bash` блокируется).
- **Атомарность и откат**:
  - Создание снимков конфигурации системы (`/etc/zsh-system-backup-<UTC>_<PID>`) и профилей пользователей (`~/.zsh-backup-<UTC>_<PID>`).
  - Генерация скриптов `restore-system.sh` и `restore-user.sh` с сохранением метаданных (UID, GID, права) и удалением conffiles, отсутствовавших до установки.
- **Миграция пользовательских настроек**: перенос алиасов, `PATH`, безопасных `export` и `source` из `~/.bashrc` и `~/.bash_profile` в отдельный блок маркёров внутри `.zshrc`. Фильтрация несовместимых переменных (`PS1`, `PROMPT_COMMAND`, `ZDOTDIR`, `FPATH`).
- **Pre-switch Validation Gate**: проверка работоспособности zsh под учётной записью каждого пользователя перед переключением shell. Дифференциальный зонд в чистом окружении для разделения локальных и системных сбоев.
- **Идемпотентность**: повторный запуск не вносит мутаций и завершается с кодом `0`.

## Требования

- ОС: Debian (тестировалось на Debian 13 Trixie) или Debian-based Linux.
- Утилиты: `bash`, `getent`, `flock`, `apt-cache`, `apt-get` (стандартный состав Debian).
- Доступ к репозиториям пакетов для установки обязательного пакета `zsh` (плагины `zsh-syntax-highlighting`, `zsh-autosuggestions`, `command-not-found` ставятся best-effort).
- Права root или доступ к `sudo`.

## Быстрый запуск (одной командой в терминал)

Вставьте команду в терминал на целевой машине:

**Через curl:**
```bash
curl -fsSL https://raw.githubusercontent.com/SERG1BY/zsh/main/kali-zsh-setup.sh | sudo bash
```

**Либо через wget:**
```bash
wget -qO- https://raw.githubusercontent.com/SERG1BY/zsh/main/kali-zsh-setup.sh | sudo bash
```

*(Если вы уже работаете под пользователем `root`, достаточно выполнить `curl -fsSL ... | bash` или `wget -qO- ... | bash`).*

## Пошаговая инструкция по запуску

### 1. Копирование скрипта на целевую систему

Скопируйте файл `kali-zsh-setup.sh` на целевую машину любым удобным способом:

```bash
scp kali-zsh-setup.sh user@target-host:~/
```

### 2. Запуск предварительного аудита (`--preflight`)

Выполните аудит без внесения изменений в систему. Проверяются кандидаты пакетов, окружение, синтаксис ZDOTDIR и права домашних каталогов:

```bash
bash ~/kali-zsh-setup.sh --preflight
```

- Выход с кодом `0`: система готова к развёртыванию (предупреждения допустимы).
- Ненулевой код: обнаружены критические блокирующие факторы (отсутствие кандидата `zsh`, некорректный sha256 шаблона, системный ZDOTDIR).

### 3. Развёртывание

Запустите установку:

```bash
bash ~/kali-zsh-setup.sh
```

*(Если запуск выполнен не под root, скрипт попытается повысить привилегии через `sudo`. Если пользователь не состоит в sudoers, переключитесь на root через `su -` и запустите: `bash /home/sippo/kali-zsh-setup.sh`).*

### 4. Проверка результата

Проверьте текущую оболочку и оформление приглашения:

```bash
# Проверка шелла в /etc/passwd
getent passwd "$USER"

# Тест prompt и подсветки синтаксиса
TERM=xterm-256color zsh -i -c 'print -r -- $PROMPT; print -r -- $ZSH_HIGHLIGHT_VERSION'
```

## Откат изменений (Rollback)

В случае необходимости ручного отката:

1. **Системные файлы**:
   ```bash
   sudo /etc/zsh-system-backup-latest/restore-system.sh
   ```
2. **Файлы пользователя**:
   ```bash
   ~/.zsh-backup-latest/restore-user.sh
   ```

## Тестирование

В репозитории предусмотрен тестовый сьют с изолированными фикстурами:

